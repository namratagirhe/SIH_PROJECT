# Machine Learning Data Directory

This directory contains raw and processed data used for training and evaluating the bovine mastitis early forecasting model.

- `raw/`: Raw CSV dataset files downloaded from validated research repositories (e.g., Mendeley Data, Kaggle Bovine Health).
- `processed/`: Preprocessed dataset splits (train, validation, test) with laboratory/sensor columns stripped out.

> [!CAUTION]
> Do NOT store sensitive or non-open proprietary records here. Synthetic datasets used for testing are saved separately and tagged as `SYNTHETIC DEMO DATA — NOT FOR CLINICAL VALIDATION`.
